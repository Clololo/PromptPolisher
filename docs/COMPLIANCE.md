# 合规与风险说明

## 1. 结论先行

**应用默认使用免费网页版（DeepSeek/豆包）**；官方 API 与手动模式作为可选备用。

网页版自动化是**实验性**功能，仅在以下条件同时满足时使用：

1. 平台的服务条款允许你以自动化方式访问；
2. 你使用自己的账号，不共享/不盗用他人会话；
3. 你不绕过验证码、风控、付费墙或访问控制；
4. 你接受账号被平台限制/封禁的风险；
5. 你不进行大规模抓取或商业转售。

如果平台禁止自动化，请改用手动模式或官方 API。

## 2. 三种路径的合规性

| 路径 | 合规性 | 稳定性 | 推荐度 |
|---|---|---|---|
| **免费网页版（默认）** | 取决于平台条款 | 低（DOM 会变） | ★★★（仅限明确允许时） |
| **官方 API（可选）** | 高（遵守 API 条款/计费） | 高 | ★★★★★ |
| **手动模式** | 高（用户自己操作网页） | 高（人工） | ★★★★★ |

## 3. 应用做了什么

- 使用 **内嵌 WebView2**，不弹出外部浏览器；
- 首次登录由用户**手动完成**（扫码/手机号），应用不代填密码；
- 会话保存在 WebView2 的加密 profile 中，供后续复用；
- 页面操作是“像用户一样”填输入框、点发送、读回复；
- 检测到验证码/安全验证/风控页面时**立即停止**，返回 `CAPTCHA_REQUIRED`，不尝试绕过；
- 提供官方 API 与手动模式作为替代；
- 日志脱敏，不记录完整 Prompt、Cookie、Token。

## 4. 应用没有做什么

- ❌ 不破解登录、不逆向接口、不伪造签名；
- ❌ 不识别/绕过验证码（图形、滑块、短信、人脸等）；
- ❌ 不规避风控、限流、设备指纹；
- ❌ 不绕过付费墙/会员限制；
- ❌ 不抓取他人会话、不共享账号；
- ❌ 不批量注册/养号/爬取；
- ❌ 不把 Cookie/Token 导出到配置或日志；
- ❌ 不保证网页版长期可用。

## 5. 凭据与隐私

| 数据 | 存储位置 | 保护 |
|---|---|---|
| API Key | Windows Credential Manager；失败时 DPAPI 加密文件 | 不明文落盘；不回显 |
| 网页 Cookie/Token | WebView2 user data folder | Chromium 加密；应用不读取 |
| 历史 Prompt/结果 | `%LocalAppData%\PromptPolisher\history.db` | 本地 SQLite；可关闭正文存储 |
| 日志 | `%LocalAppData%\PromptPolisher\logs` | 正则脱敏；默认不记录 Prompt |
| 配置 | `%LocalAppData%\PromptPolisher\settings.json` | 只存非敏感设置 |

## 6. 用户责任

- 阅读并遵守所选平台的服务条款、隐私政策、计费规则；
- 不使用自动化功能处理违法、侵权、虚假信息、骚扰等内容；
- 不将账号借给他人或共享会话；
- 对 Prompt/输出中的敏感信息（PII、商业机密）自行脱敏；
- 出现验证码/风控提示时，停止自动化，改用官方 API/手动模式。

## 7. 平台条款提示（非法律意见）

多数对话产品会在服务条款中限制“自动化访问、爬虫、逆向、绕过技术措施”。是否允许取决于具体平台与账号类型。**本应用不替用户做合规判断**；启用网页版前的确认框只是提醒，不构成授权。

如平台明确禁止自动化，请使用：

1. 官方 API（DeepSeek Platform / 火山方舟）；
2. 手动模式：应用生成 Prompt，你复制到网页版，结果粘贴回来。

## 8. 事件响应

如果账号被限制或收到平台警告：

1. 立即停止网页版自动化；
2. 删除 WebView2 会话目录（`%LocalAppData%\PromptPolisher\webview`）；
3. 改用官方 API/手动模式；
4. 必要时联系平台申诉。
